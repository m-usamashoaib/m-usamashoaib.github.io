# Muhammad Usama Shoaib · Developer Portfolio

Personal portfolio of a MERN stack engineer with 4+ years building e-commerce, SaaS and healthcare web apps.

**🔗 Live site:** https://m-usamashoaib.github.io

## Features

- **Data-driven:** all content (projects, experience, skills, testimonials) lives in one file, [`data.js`](data.js), and the page renders itself from it
- **Project case studies** in a problem → solution → result format, with category filters
- **Dark / light theme** that follows the system preference and remembers the visitor's choice
- **Responsive** layout with a mobile menu
- **Typewriter hero, scroll-reveal animations** and active-section highlighting in the nav (all respect `prefers-reduced-motion`)
- **Contact form** that posts to Formspree when configured, or falls back to `mailto:`
- **No framework, no build step:** plain HTML, CSS and JavaScript, loads instantly and deploys anywhere

## Tech

HTML5 · CSS3 (custom properties, Grid, `color-mix`) · Vanilla JavaScript (ES6+, IntersectionObserver)

## Run locally

It's a static site, so open `index.html` in a browser or serve the folder:

```bash
npx serve .
```

## Customise

Edit [`data.js`](data.js) to change any content. To receive contact-form messages by email, create a free form at [formspree.io](https://formspree.io) and paste its endpoint into `formEndpoint`.
